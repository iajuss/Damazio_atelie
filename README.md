# Damazio Atelier

Catálogo consultivo do Damazio Atelier, desenvolvido com Next.js, TypeScript e Tailwind CSS.

## Requisitos

- Node.js 20.9 ou superior
- pnpm

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Verificações

```bash
pnpm lint
pnpm vitest run
pnpm build
pnpm playwright test src/test/e2e/home.spec.ts
```
